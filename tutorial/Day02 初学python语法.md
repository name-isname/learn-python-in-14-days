# Day02 初学python语法
在zed的编辑器下写python代码，写一个猜数字的程序

猜数字
程序会生成一个目标随机数字，用户在终端里输入一个数字，程序会给出输入数字和目标数字比大了还是小了。不断循环这个过程，直到用户输入对了这个数字。

需要掌握
- 输入与输出
- 流程控制，循环和判断
- 生成随机数
- 定义变量
- 基本变量类型

要点
先学习要掌握的几个部分，每个学完了就去手动写代码运行，练一下。这个是很必要的，要有代码的基础才行，别人不掌握是因为根本不打算从事这个行业，但是去做笔试是需要会写代码的。其次命令行也是必要的，要会手操命令行，有些东西是很新，这些AI没有语料，不一定能做对。所以要掌握通用的能力。
可以和AI交流写代码，但是需要理解代码里面的每一句是什么意思。不能照搬AI代码，自己手写一遍。
附件python cheat sheet里全是语法精要，用来查的，不要先看懂这个pdf再去写程序
