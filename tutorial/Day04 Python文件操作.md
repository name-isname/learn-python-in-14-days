# Day04 Python文件操作与初识包
学习python中如何操作电脑上的文件，至少了解open()函数，with as关键字，各种操作文件模式如w/a。动手实现写入一个txt文件。

初识包这个概念，了解包在python里的作用，什么是包管理。使用`uv init`初始化项目，不带`--no-package`。观察为什么本地项目成了一个包。尝试用`uv add`添加一个外部包。了解`__init__.py`的作用。

了解json格式，了解这个数据交换格式的语法。学会在python中使用json格式，具体说包括读取json，写入json。理解load/dump方法和loads/dumps方法的区别。
